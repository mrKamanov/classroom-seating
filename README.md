# Классная Рассадка

Android-приложение для учителей: составление, редактирование и обмен схемами рассадки учеников между кабинетами и коллегами. Работает полностью офлайн, все данные остаются на устройстве.

## Зачем это нужно

В средней и старшей школе у класса несколько кабинетов и разные учителя, поэтому
ученики часто пересаживаются сами. Классный руководитель рисует рассадку на
бумаге и носит с собой листы А4 для каждого кабинета — это медленно, теряется и
неудобно передавать предметникам.

Приложение решает это: схема рассадки всегда под рукой, меняется за пару секунд
и передаётся коллеге одним касанием.

## Возможности

**Классы и ученики**
- Создание, переименование и удаление классов
- Импорт списка учеников из журнала «Моя школа» (файл Excel), из шаблона или вручную
- У каждого ученика: ограничение по здоровью (слух, зрение, частые болезни и др.) и примечание вроде «не сажать вместе»

**Конструктор кабинета**
- Число парт в ряду и число рядов
- Положение доски: сверху, снизу, слева или справа — с предпросмотром сетки

**Рассадка**
- Перетаскивание учеников на парты пальцем
- Автоматическая рассадка с учётом ограничений по здоровью
- Случайная рассадка по кубику — если нужен новый вариант
- Предупреждения о нарушениях прямо на схеме

**Малые группы**
- Деление класса по месту, случайно, по алфавиту или вручную
- Настройка числа групп или размера группы

**Обмен рассадкой**
- QR-код, который сканируется другим телефоном
- Отправка QR-картинки или файла `.seating` в мессенджер
- Импорт: сканирование камерой или загрузка картинки из галереи
- Печать схемы в PDF с выбором ориентации листа

**Прочее**
- Встроенная инструкция с пошаговым описанием всех сценариев
- Полностью офлайн: приложение не запрашивает доступ в интернет

## Как пользоваться

1. **Создайте класс** — кнопка «Класс» на главном экране.
2. **Загрузите учеников** — откройте класс → иконка загрузки файла →
   «Загрузить из журнала "Моя школа"» (или шаблон, или вручную).
3. **Настройте кабинет** — иконка шестерёнки: число парт, рядов, положение доски.
4. **Рассадите** — иконка стульев: перетаскивайте учеников или нажмите ✨
   для автоматической рассадки.
5. **Поделитесь** — иконка «Поделиться»: QR-код, файл `.seating` или PDF.

Подробная пошаговая инструкция с иллюстрациями по кнопкам доступна прямо
в приложении: кнопка «?» в правом верхнем углу главного экрана.

## Технологии

Kotlin · Jetpack Compose (Material 3) · Room · Hilt · Coroutines/Flow ·
Navigation Compose (Type-Safe Routes) · ZXing + ML Kit Barcode · DataStore · JUnit

## Сборка из исходников

Требуется JDK 17 и Android SDK.

```bash
git clone https://github.com/mrKamanov/classroom-seating.git
cd classroom-seating

./gradlew assembleDebug        # сборка debug APK
./gradlew testDebugUnitTest    # юнит-тесты
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
