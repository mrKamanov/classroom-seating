# ClassRoom Seating — Рассадка класса

Android-приложение для учителей: быстрое создание, редактирование и обмен схемами рассадки учеников между кабинетами и коллегами.

## Проблема

При переходе из начальной школы в среднее и старшее звено ученики ходят по кабинетам, у них разные учителя, и дети часто самовольно пересаживаются. Сейчас классный руководитель рисует рассадку на бумаге и носит с собой листы А4 для каждого класса — это медленно и неудобно делиться с предметниками.

## Идея продукта

Простой и быстрый инструмент для учителя: за пару кликов составить и отредактировать схему расстановки парт и учеников в кабинете, сохранить её, перевести учеников из класса в класс и передать коллегам без лишней рутины. Всё работает оффлайн, запускается за секунды на перемене и избавляет от путаницы при переходе между классами.

## Подход к разработке

Проект ведётся по методике **Documentation-Driven Development**: специализации определяют архитектуру, схему БД, UI и план работ, что исключает путаницу и упрощает ввод в проект новых разработчиков.

## Возможности

- **Классы и ученики.** Создание классов, импорт списка учеников из журнала «Моя школа» (Excel), из шаблона или вручную; у каждого ученика можно задать ограничение по здоровью и примечание.
- **Конструктор кабинета.** Сетка парт, число рядов, положение доски (сверху, снизу, слева, справа) с предпросмотром.
- **Рассадка.** Перетаскивание учеников мышью/пальцем, автоматическая рассадка с учётом ограничений, случайный вариант по кубику.
- **Малые группы.** Деление класса по месту, случайно, по алфавиту или вручную.
- **Обмен рассадкой.** QR-код, отправка QR-картинки или файла `.seating` в мессенджер, печать в PDF, импорт по QR-камере или из галереи.
- **Встроенная инструкция** с пошаговым описанием всех сценариев.
- **Полностью оффлайн**: все данные хранятся локально в Room.

## Стек технологий

Kotlin · Jetpack Compose (Material 3) · Room · Hilt · Coroutines/Flow · Navigation Compose (Type-Safe) · ZXing + ML Kit Barcode · DataStore · JUnit

## Сборка

Требуется JDK 17 и Android SDK.

```bash
git clone https://github.com/mrKamanov/classroom-seating.git
cd classroom-seating
./gradlew assembleDebug        # сборка debug APK
./gradlew testDebugUnitTest    # юнит-тесты
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
